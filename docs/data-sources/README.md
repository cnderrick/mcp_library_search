# 数据源总目录

本目录按**国家／地区**分卷登记各图书馆数据源的线上入口、技术组件与接入要点。
每卷一个文件，文件名取该地区的域名后缀（ccTLD），与代码里 `region` 参数的取值一致。

## 分卷

| 地区 | 文件 | 覆盖范围 |
|---|---|---|
| `cn`（中国） | [cn.md](cn.md) | 中国大陆各省市公共图书馆；含已接入、攻关中与待核验的全部条目 |
| — | 未来 `us.md`、`jp.md`… | 接入其他 ccTLD 时按同规矩新增 |

## 与其它文档的关系

- **[AGENTS.md](../../AGENTS.md) 只指向本总目录**，不展开分卷内容。
- 分卷是登记正文；字段级细节回溯到 `tests/fixtures/<city>/NOTES.md`。

## 登记约定

1. **新城市先在对应分卷的总览表登记一行**，再写接入要点；一个系统对多座城的，
   城市差异收在该系统章的城市表里。
2. 分卷内部结构（总览表列、状态标识、接入系统分章）以 [cn.md](cn.md) 为范本，
   新分卷照此组织。
3. 文件名＝ccTLD，与 `src/mcp_library_search/adapters/<region>/` 子包、`region`
   参数三者一致；新增地区＝新建分卷 ＋ 新建适配子包。
4. 中文注释与文档一律用全角标点（仓库铁律，见 [AGENTS.md](../../AGENTS.md)）。
